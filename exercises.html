How to use this collection

One set per chapter. Each chapter of the course has a set of problems, numbered by chapter: Problem 3.4 is the fourth problem of the Chapter 3 set. A set uses only what has been taught up to the end of its chapter; the box at the start of each set says which ideas it calls on and which data it uses.

Three levels. Within a set the problems are arranged in order of difficulty, and each one carries a label:

  • A · Understanding: reasoning with the physical picture, orders of magnitude, short arguments. No long calculation.

  • B · Guided calculation: a calculation in several steps, set out in the order in which the course builds the result.

  • C · Synthesis: problems that combine several ideas, ask for a derivation, or apply the course to a situation it did not treat explicitly.

Hints. Many problems have a hint. It tells you where to start or which idea to use; it does not give the result. Try the problem first without it.

Figures. Figures placed with a statement show the device or the set-up; they appear in both documents. Figures inside a solution show the result, a profile, a curve or a band diagram, and appear only in the worked solutions. Curves are computed with the numbers of the solution; pictures labelled ‘generic’ show shapes, not values. A figure marked ‘After Neamen, Fig. …’ or ‘After Sze & Lee, Fig. …’ is redrawn from that textbook figure.

Sources. Under the title of each problem, a line gives its origin. Original problem means that the problem was written for this course. Adapted from Neamen, Problem nnn, p. ppp or Adapted from Sze & Lee, Ch. ccc, Problem nnn, p. ppp means that the problem starts from that textbook problem; it has been rewritten for the course, usually with the data of the course, more explicit assumptions and additional questions, so that its numbers differ from those of the book. The two textbooks are

  • D. A. Neamen, Semiconductor Physics and Devices: Basic Principles, 4th ed., McGraw-Hill, 2012;

  • S. M. Sze and M. K. Lee, Semiconductor Devices: Physics and Technology, 3rd ed., Wiley, 2012.

Page numbers are the printed page numbers of these editions.

Numbers. Give results with two or three significant figures, and always with their units. When a result looks surprising, check its order of magnitude before going on: many problems ask you to compare a computed value with another one, and that comparison is usually the point of the problem.
